# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include a sensitive test image in any report. Use GitHub's **Security → Advisories → Report a vulnerability** flow to create a private security advisory for this repository. Include affected commit/version, impact, reproduction steps using synthetic data, and any suggested remediation.

Maintainers should acknowledge a report within seven days, coordinate validation and a fix privately, and publish details only after users have had a reasonable opportunity to update. If private advisories are unavailable, contact the repository owner privately through the contact method shown on their GitHub profile; do not transmit real personal images.

Only the latest commit on the default branch is supported. No deployment workflow is provided in this version. Reports about future hosting logs, third-party manual-upload services, compromised clients/extensions, or unavoidable JavaScript memory-erasure limitations may be out of scope unless they demonstrate a defect in this application's stated controls.
